# AStock · 量化研究与模拟交易

AStock 是 Windows 本机应用，用于编写 Python 策略、历史回测、报价快照回放，以及真实行情下的虚拟资金交易。所有委托都在本地模拟，不连接券商交易账户。

## 下载 0.6.1

在 [GitHub Releases](https://github.com/winter-warm/astock/releases/latest) 下载 `AStock-0.6.1-Windows-x64.zip`，完整解压后运行 `AStock/AStock.exe`。课程练习包为 `AStock-0.6.1-Notebooks.zip`，源码包为 `AStock-0.6.1-source.zip`；发布页同时提供 SHA256 校验文件。

本版汇总 0.6.0 后的界面与数据修复：统一策略接口、回测设置和布局操作；教学 K 线使用确定性自然波动样本；图表、数据选择和报告明确区分合成教学、真实历史与录制行情；指数可以用于研究和信号计算；快照速度只影响快照回放。公开包首次启动生成离线教学数据，真实历史数据通过软件内下载或导入；本机已有账户、策略、学习记录和行情缓存不随发布包分发。

## 从哪里开始

打开应用后直接进入“写策略”，中央就是源码编辑器。主入口统一在左侧：

| 页面 | 用来做什么 |
| --- | --- |
| 写策略 | 新建、选择模板、编写 Python、检查参数和保存 |
| 历史回测 | 核对待运行策略、配置历史实验，查看历史回测与快照回放的结果 |
| 模拟交易 | 连接报价、管理实时策略与手动练习账户，暂停、继续或停止模拟执行 |
| 数据中心 | 搜索证券，下载、导入、检查和选择行情数据 |
| 账户与记录 | 只读归档所有账户与运行，核对依据、导出报告、比较结果 |
| 量化课程 | 按 12 个模块学习完整的 72 课 |

第一次启动会显示 35 步使用教程，每步高亮实际控件，并写明用途、操作和核对结果。章节包括写策略、数据与费用、回测准备、回测运行、读取结果、模拟交易、记录与课程；可以从章节选择器直接重看所需部分。引导只切换页面和高亮位置，不自动保存、运行或下单。可以随时结束，再从“帮助 → 使用教程重放”重新查看。

## 第一次回测

1. 在“写策略”点击“模板与已存策略”，选择双均线趋势模板；也可新建自己的策略。
2. 中央编写代码；修改 PARAMETERS 声明后打开右侧“参数设置”，点击“检查参数”，再设置实际数值。
3. 点击“保存”或按 Ctrl+S。不同实验用“另存副本”保留自己的版本。
4. 点击“去回测”，当前编辑草稿和参数会成为待运行策略。先核对顶部策略名和来源，再检查数据、日期区间、基准、本金和费用；已有结果仍显示其原运行来源。
5. 选择明确标注的教学日线数据，点击“开始回测”。默认只显示选择策略、回测设置和开始回测；需要暂停、继续、单步或停止时勾选“展开运行控制”。
6. 在结果页核对净值、回撤、运行依据及委托成交。改一个参数建立独立运行后，到“账户与记录 → 运行对比”比较数据、费用和规则相同的结果。

教学数据是人工构造的流程样本，不是真实市场收益证据。真实数据下载后，先检查日期覆盖、缺口和历史证券规则；程序不会在网络失败时暗中替换成合成数据。

## 模拟交易

“模拟交易”只展示实时策略与手动练习账户，历史回测和快照回放在“历史回测”查看。先核对证券和报价新鲜度，再创建虚拟账户；选中账户并点击“查看账户”后，顶部控制只作用于这个模拟账户。历史归档、报告和跨运行比较统一在“账户与记录”，选择记录不会重启策略。

历史回测和快照回放暂停时保留待成交委托；实时仿真暂停会撤销未成交委托。需要结束整个账户时使用“停止并撤单”，再核对剩余委托和冻结资金。

## 72 课量化课程

“量化课程”只保留这套长期课程。前六课按照已有股票交易、C++ 和数据结构基础压缩；后续逐步讲数据、指标、策略、回测、风控、因子、机器学习、CPU 深度模型和 AI 研究方法。正文包含推导、手算、代码、实验、练习与答案。

阅读器支持搜索、课内目录、书签、字号、阅读位置、答案折叠和知识自测。基础 Python 示例可以在软件中运行并查看表格、曲线；策略例载入新的教学副本后进入写策略页面。进阶示例可导出单课或全部 Notebook，附 uv 锁文件和启动脚本，使用独立 CPU 环境。首次安装 Notebook 依赖需要网络；AI 示例默认离线，真实接口需要主动配置。

应用使用教程和量化知识课程分别负责操作与学习。旧版互动教程、QMT 迁移课、任务目录不再作为页面或帮助菜单入口；已有学习记录保留。

## 初始化应用

“帮助 → 初始化应用”会在确认后停止应用任务，清除本地策略、账户、运行记录、行情数据、日志、报告和设置，再恢复首次启动状态。**不备份，删除无法撤销。** 阅读进度、自测、书签、练习草稿与 Notebook 保留。取消确认不会清除数据。

## 打开与保存

重复打开时会切回已经运行的窗口，不再启动第二个应用。正常退出后可以重新打开；异常退出不会留下一个永久阻止启动的状态。

完整解压 Windows 软件包后双击 AStock.exe；保留旁边的 _internal，不能只移动 EXE。软件本身无需额外安装 Python。便携模式的数据位于 EXE 旁的 data，关于窗口会显示实际位置。

源码启动需要 PowerShell 7 和 uv：

```powershell
./Start-AStock.ps1
```

开发时可以用独立数据目录：

```powershell
uv sync --frozen --python 3.12
./.venv/Scripts/python.exe -m astock --data-dir ./data
```

教程和界面随版本一起复核，构建不会只凭版本号接受旧报告。流程见 [教程维护](docs/TUTORIAL_MAINTENANCE.md)，版本验收记录见 [实现与验收记录](docs/TUTORIAL_IMPLEMENTATION_STATUS.md)。
