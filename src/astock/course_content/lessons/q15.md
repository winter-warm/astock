# 相关性：一起涨跌，不等于互相导致

## 为什么组合研究需要它
你可能买了几只名称不同的证券，以为已经分散风险。但如果它们在相同时期总是一起涨跌，账户可能仍主要暴露于同一种变化。相关性为“一起变化”提供一个数值描述，后面组合配置和因子去重都会用到它。

本课用人工收益构造三组序列。B 是 A 的两倍再加一个固定偏移，C 是 A 的相反数。这样我们提前知道答案，能核对矩阵排列和公式。真实市场不存在这么整齐的永久关系，例子只用于理解计算。

## 从协方差到相关系数
协方差观察两组数据是否同时偏离各自均值：两边同时高于均值或同时低于均值时，偏差乘积为正；一高一低时为负。平均这些乘积就得到共同变化方向的量。它有单位，且会受尺度影响。

相关系数再用双方标准差把协方差标准化。Pearson 相关系数位于 -1 到 1 之间，1 表示完全正线性关系，-1 表示完全负线性关系，接近零表示本样本中线性共同变化弱。这里“线性”两个字不能省略；没有线性相关并不意味着没有任何关系。

## 读懂相关矩阵
矩阵第 i 行、第 j 列是对应两组序列的相关系数，对角线一般是自身与自身的相关。例子用 vstack 把每个变量放在一行，与 np.corrcoef 默认 rowvar=True 配合。如果你的 DataFrame 每列是一只证券，转成数组后需要相应调整参数或转置。矩阵是 5×5 还是 3×3 往往能帮助发现方向错误。

A 与 B 的相关为 1，但 B 的波动是 A 的两倍。高度相关不表示收益幅度相同，也不表示两者可以无成本互相替代。A 与 C 的相关为 -1，是我们人为构造的结果；实际寻找负相关资产时，关系可能随时期变化，而且交易成本和可投资性也需要考虑。

## 零相关的反例
代码还计算 x 与 x²：x 取 -2、-1、0、1、2，y 完全由 x 决定，但 Pearson 相关为零。左右对称的正负偏差抵消了线性协方差。这说明相关系数不是关系探测器的全部。散点图、分组统计和对机制的理解可以提供额外信息。

反过来，高相关也不能证明因果。两只证券可能同时受市场因素影响；两列价格也可能因共同趋势而呈现高相关。若要研究共同的短期涨跌，通常先明确使用同频收益而不是直接比较价格水平。无论使用哪种输入，都应解释它对应的问题。

## 时间对齐先于统计
上一模块已经强调标签和日期。这里更要保证 A 和 B 的每一对数值来自同一可比较区间。如果 A 是当日收盘收益，B 是滞后一天的收益，相关性可能被错误地减弱或放大。缺失时只保留共同样本，也应同时报告有效数量，不能只给相关矩阵而隐藏不同格子的样本差异。

相关计算通常会去掉无效配对，但如果某只证券仅在少数平静时期有记录，它与其他证券的相关就可能带有选择偏差。先查覆盖范围，再解释数字。没有波动的常量序列标准差为零，相关系数不可定义，不应硬填成零或一。

## 稳定性与窗口
全样本相关只是一个汇总。你可以分别算前半段、后半段，或使用滚动窗口观察关系变化。窗口太短估计会很不稳定；太长又可能掩盖结构变化。窗口长度是研究选择，不存在仅凭公式确定的最佳值。

若根据全样本相关筛选策略，再在同一段数据上展示组合效果，结果已经使用了该段信息。需要把筛选和评价区间分开，后续样本外课程会具体实现。学习相关性时就记住：统计量也有它的可知时刻。

## 改参数实验
给 B 加一组固定的小扰动，观察相关不再恰好等于 1。再将 A 整体乘 100，验证相关不变而协方差变化。这样可以把“尺度敏感”与“尺度标准化”的区别落到数字上。

## 练习

1. A 与 B 的相关为 1，能否据此判断谁收益更高？
2. 相关为零能否直接认定独立？
3. 某证券所有收益都相同，为什么相关出现 NaN？

## 参考答案

1. 不能。相关主要描述线性共同变化，均值和尺度要另看。
2. 不能，x 与 x² 就是反例；一般分布下零相关弱于独立。
3. 标准差为零，标准化分母无定义；不是程序随意遗漏结果。


## 用一个比例关系核对尺度
B 等于二倍 A 加零点三个百分点。加上固定常数会改变均值，但减去各自均值后，这个常数消失；乘二使偏差和标准差都乘二。协方差与标准差乘积中的比例相互抵消，所以相关仍为一。这个推导解释了为什么高相关并不表示收益幅度相同。

C 等于负 A，偏差方向相反，协方差为负，标准差仍为正，相关得到负一。真实组合里若想利用负相关降低波动，还要检查它是否能保持、是否可交易以及是否需要额外融资，不能仅凭一张历史矩阵就确定仓位。

## 价格水平相关的陷阱
两组互不相关的增量序列累计后都可能形成缓慢漂移的价格水平。直接比较价格，会混入趋势和非平稳性。研究同期间共同涨跌时，收益序列通常更贴近问题；研究价格之间的长期关系则需要另外的时间序列方法和假设。

这不是说价格相关永远不能看，而是要求你说明统计对象。把价格、收益、成交量和信号列全放进相关矩阵，可能得到很多数字，却没有统一解释。先写出要检验的问题，再选择对应输入，比让软件一次输出所有列更有帮助。

## 相关矩阵为什么也会变化
用前半段和后半段分别估计相关，可能得到不同结果。一方面是样本随机性，另一方面可能是市场结构、行业暴露或策略行为变化。不能只选符合预期的那一段做结论。应预先约定窗口，并观察结果随窗口改变是否稳定。

滚动相关的相邻窗口大量重叠，因此曲线看起来平滑并不等于每一点都是独立证据。一个异常事件会在窗口中停留很多期，持续影响估计。解释某一段相关升高时，回看构成窗口的实际数据很重要。

## 为常量和缺失写规则
当任一输入没有波动时，相关不可定义。把它填成零会让人误以为已经证明两者没有线性关系；把它填成一也没有依据。保留缺失并说明原因，是比强行获得完整矩阵更准确的处理。

缺失配对后还要检查有效数量。例如两只证券只在两天有共同记录，算出接近一的相关并不令人意外，也没有多少稳定性证据。报告矩阵旁边的有效样本数，有时比相关值多保留三位小数更有价值。
