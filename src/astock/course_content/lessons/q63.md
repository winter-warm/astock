# 训练一个 MLP：把窗口摊平，也把研究边界保留下来

## 你已有的理论在这里对应哪些代码
MLP 的线性层和非线性激活你可能已经熟悉。本课真正需要练的是：把八期窗口变成网络输入，明确目标尺度，保存验证最好的参数，并在训练结束后只用冻结模型评价测试。网络只有一个十六维隐藏层，足以展示完整流程，也能在普通 CPU 上快速运行。

输入形状仍是样本数×8×1，Flatten 将后两维合并成八个特征。它不会自动理解先后关系；第一个和最后一个位置只是不同输入坐标。因为窗口长度固定，网络可以学习位置相关权重，但这种方式不具备序列模型的参数共享结构。

## 人工数据中的信号有意保持简单
本课序列 r_t 由上一期的 0.35 倍加噪声生成，目标是下一期值。这里的数值是人工过程单位，不是实际证券收益百分比。不要把打印的 MSE 当作真实金融绩效。之所以使用可控过程，是为了在模型实现和时间验证正确后，再讨论真实数据的不确定性。

均值和尺度只从训练窗口估计。训练、验证与测试按连续时间划分，并在边界留出标签间隔。模型不会因为换成神经网络就获得访问未来的特权；前面建立的所有时间元数据与断言继续存在。

## 从完整脚本拆出训练职责
fit 每轮先进入 train 模式，清梯度、前向、计算 MSE、反向，再用 Adam 更新。梯度裁剪限制一次更新前的梯度范数，帮助避免偶发数值不稳定，但它不会解决数据泄漏或错误目标。验证阶段切 eval 并使用 no_grad，保证 dropout 不再随机丢弃单元，也不记录计算图。

当验证误差降低时，deepcopy 保存当时的 state_dict。如果只写 state = model.state_dict() 而没有复制，字典中的张量可能继续随模型训练变化，最后“最佳参数”实际上变成末轮参数。这是非常值得亲手检查的实现细节。

## 为什么看两条曲线
训练误差通常更容易下降，验证误差可能在某时刻不再改善。两条曲线分开画，能看到模型是否继续记忆训练噪声。最后加载的是验证最佳状态，不是无条件使用训练最后一轮。测试误差只在选定状态之后计算，不用于决定训练轮数。

曲线的上下关系也受 dropout 影响。训练时随机失活，评价时关闭，因此某些时刻训练损失不一定严格小于验证损失。不要仅凭一条曲线略高就判定代码错误，应先核对两者的模式、数据和计算方式。

## 正则化与容量各自改变什么
隐藏层从 16 改为 64 会增加参数和表达能力，也增加有限样本中过拟合的机会。dropout 通过训练时随机失活提供一种正则化；把概率调得很高可能连有用信号也学不出来。正则化不是越强越好，它和数据量、信号强度及优化过程有关。

本例使用固定轮数加“保存最佳验证状态”，这与早停相近但不会提前终止计算。你可以增加 patience 实现真正早停，前提是只看验证段。不要根据测试误差最小的轮数回头挑模型，那相当于把测试当验证。

## 与简单基线比较
baseline 预测训练目标均值，完全不看当前窗口。测试 MSE 与它比较，才能知道网络是否提供超出常数的预测能力。还应与第 57 课的线性模型比较，因为人工过程本来就接近线性；一个更复杂 MLP 不一定有优势。

即使预测误差稍低，也还没有证明可交易收益更好。将分数转成仓位后，阈值、成本和执行约束可能改变结论。这里先把模型学习流程验证好，下一步再接回已经学过的研究评价链。

## 参数实验
保持数据种子与划分不变，比较隐藏层 4、16、64；只在验证段选一个，再统一报告测试。记录参数数量和训练耗时，避免只比较最佳一条曲线。接着将 dropout 改为 0 和 0.3，观察训练与验证差距，而不是预设必须改善。

还可以把目标替换为与输入独立的随机序列，检查网络是否只降低训练误差。这个对照不应变成寻找“偶然好测试”的种子游戏；固定实验配置并保留全部结果。

## 报错与排查
若预测形状为 N 而目标为 N×1，先修正输出维度。若 loss 出现 NaN，检查原始数据、缩放标准差、学习率和梯度。若每次运行结果变化很大，先确认种子、模型初始化、dropout 模式和环境版本，再讨论统计波动。

## 这张小网络到底有多少自由度
八个历史收益进入十六个隐藏单元，第一层需要八乘十六个权重和十六个偏置，第二层需要十六个权重和一个偏置，总计一百六十一个可训练参数。训练样本只有两百行，而且相邻窗口高度重叠；样本数看似略多于参数量，并不能据此认定泛化足够。参数计数帮助你理解模型规模，却不能替代时间样本外评估。

本课的非线性来自隐藏层激活。若删掉激活，仅保留两个线性层，它们复合后仍然是一种线性映射，增加层数不会凭空获得非线性表达能力。你可以把隐藏宽度改成八、十六、三十二，事先规定相同轮数与选模规则，观察训练与验证误差差距。宽模型训练误差下降更快，而验证误差没有同步改善，是值得记录的结果，不是代码失败。

固定环境的一次结果中，最佳验证误差约为一点一五三，测试误差约为一点二六五，常数基线约为一点二六九。差异很小，不能因为神经网络略低就宣布学到了可交易优势。我们的人工标签以单位量级波动，误差也使用这一尺度；它不是百分之一收益的误差，不能直接与前面使用小数收益的岭回归表横向比较。

训练曲线有两个不同时间点：训练损失通常在参数更新前记录，验证损失在更新后、评价模式下记录。再加上训练时启用随机失活，训练与验证数值不完全一致并不奇怪。若要做严格同状态比较，可以在每轮更新后另用评价模式计算训练误差，但要标明它与优化过程实际使用的损失有区别。

保存最佳状态必须复制参数内容。若仅让变量指向当前模型的状态字典，后续训练可能继续改变其指向的张量，最终所谓“最佳轮”实际上还是末轮。代码使用深复制，并在训练结束后恢复，再计算测试误差。你可以故意用最后一轮替代最佳轮，观察验证表变化；修复后再保留正式结果。

梯度裁剪将梯度范数限制在规定范围，主要用于避免个别更新过大。它并不修复泄漏，也不证明模型已稳定。若每轮都强烈触发裁剪，应检查标签尺度、学习率和异常输入。还可以记录梯度范数，但不要把降低裁剪阈值当成掩盖发散的万能办法。
