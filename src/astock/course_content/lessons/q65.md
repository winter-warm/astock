# 小型 Attention／Transformer：把维度、位置与掩码接对

## 从你熟悉的公式走到实际输入
你已经了解 attention 可以根据 query、key 和 value 计算加权关系。落到金融序列时，首先要确定 token 是什么。本课一个 token 对应一个历史观察时点，原始特征只有一维收益。Linear(1,8) 将每个时点映射到八维表示，随后才进入两头注意力。

注意力头数必须与表示维度兼容，八维可以分成两个头。这里使用非常小的维度，是为了学习接口和验证时间语义，不是推荐的真实交易网络规模。模型参数更多不代表能从有限金融样本中稳定提取更多信息。

## 位置为什么不能省略解释
仅靠内容注意力，模型不能自然知道哪个观察更早、哪个更晚。position 是长度八的可学习位置表示，加到每个 token 上，使同一个数值出现在不同历史位置时有不同表示。它初始为零，训练过程中可以学习；零初始化不意味着一直没有位置信息。

窗口长度改变时，位置表示长度也要改变，不能把十六期输入硬塞进只定义八个位置的模型。还可使用固定正弦位置编码或相对位置设计，但比较时应把它们视作新的候选，不用测试结果挑一个最好再声称原方案有效。

## 掩码真正限制了什么
本例用上三角布尔掩码屏蔽每个位置之后的 token，使第 j 个位置只看 0 到 j。模型最终取最后一个位置预测下一期，最后位置可以访问整个合法历史窗口。代码把窗口最后一个值大幅改变，检查更早位置的编码保持一致，直接验证掩码方向没有写反。

一个细节值得说明：如果任务只在完整历史窗口末端预测未来，而整个窗口都已在决策时可知，那么不使用因果掩码的历史窗口内部注意力也不一定泄漏。我们使用掩码，是为了建立清楚的逐位置因果约束，并为将来逐时点输出任务打基础。真正禁止的是访问决策之后的数据，而不是机械禁止一切双向运算。

## Encoder 与预测头
TransformerEncoderLayer 包含注意力、前馈网络、残差和归一化。我们只用一层，前馈维度十六，dropout 设为零以方便验证掩码性质。encoder 输出仍是批次×时间×表示维度，head 只作用在最后一个时间位置，得到批次×1 的回归预测。

如果直接对全部位置输出再与一个批次×1 的目标计算损失，可能触发广播或使每个历史位置都拟合同一个未来标签。那不是本课定义的任务。明确选择 [:,-1] 并断言形状，是比凭经验观察训练损失更可靠的接口检查。

## 训练与验证仍保持相同口径
数据、缩放、时间切分和验证选最佳状态与 MLP、LSTM 相同。这里训练四十五轮以控制 CPU 时间，比较时要记录这一差异，不能把不同训练预算造成的结果全部归因于结构。第 66 课会将各模型放进统一对照表。

模型用固定小数据，测试 MSE 不一定胜过更简单方法。注意力模型能够表达复杂关系，和样本中存在可泛化复杂关系，是两个不同命题。人工生成过程接近简单线性，本来就没有理由要求 Transformer 必须赢。

## 从异常现象回到检查
如果修改最后 token 竟改变早期输出，先确认 eval 模式、dropout、掩码方向与数据复制。随机 dropout 会让两次前向本来就不同，因此本课检查放在 eval 和 no_grad 下。若掩码全为 True 或方向反了，可能让位置无法看到正确历史，产生不稳定甚至 NaN。

模型数值正常也不说明研究无泄漏。归一化可能使用未来样本，标签可能与输入重叠，训练测试也可能随机混排。掩码只限制网络内部 token 访问，不能自动修复数据管道外部的问题。

## 参数实验
将 nhead 从二改为一，保持 d_model=8，比较参数量和验证结果。再尝试 nhead=3，应看到维度不兼容提示；这是配置约束，不应靠随意 reshape 绕过。将窗口从八改为十六时，同时更新样本构造、位置长度和任何依赖窗口的检查。

另外可在固定训练段上比较有无位置表示。有时结果差异不明显，尤其人工过程主要依赖最后一个值。把没有显著改善的结果记录下来，能帮助判断结构是否确实需要，而不是为了“用了注意力”而保留复杂度。

## 用四个位置手画注意力遮罩
把窗口暂时缩成四个位置，第一行只能关注第一个位置，第二行可以关注前两个，第三行关注前三个，第四行关注全部四个。对应禁止区域位于主对角线的右上方。代码使用布尔遮罩，其中真表示禁止关注。不同接口对遮罩的约定可能不同，移植时要读接口说明，不能看到零和一就想当然地复用。

本课用最后一个位置预测下一期，该位置本来就能合法读取整个历史窗口。遮罩的额外作用是让较早位置的表示保持因果性质。修改最后一个输入后，前面位置的表示应保持不变，而最后位置可以改变。这个断言比只检查遮罩矩阵长得像三角形更有用，因为它直接验证信息是否穿过了被禁止的路径。

如果你改成对窗口中每个位置都预测下一步，遮罩就更加关键。没有遮罩时，第一个位置的表示可能直接读取第二个输入，而第二个输入恰好就是它要预测的目标。整段窗口虽然都来自历史，对其中较早决策点仍然包含未来。时间泄漏必须相对于每个预测位置判断，不能只根据整段数据在今天以前就认定安全。

输入从一维投影到八维，再加位置参数。位置参数让模型区分“最近一期”和“八期以前”，否则自注意力本身很难表达固定顺序的作用。这里使用固定窗口长度的可学习位置表，换窗口长度必须同步改变位置表和遮罩形状。它不是一个可以自动接收任意长历史的成熟模型，外推到更长序列需要重新设计与验证。

八维表示拆成两个头，每个头的维度是四。多头让不同投影有机会关注不同关系，但不能预先给某个头贴上动量或风险标签。注意力权重也不自动构成因果解释，输出还受投影、残差、前馈层与训练目标影响。研究中可以用扰动输入与删除特征做补充检查，但依然不能把相关变化解释成经济因果。

固定设置的一次测试误差约为一点一七六。你可以把头数改成一和二，在验证段比较；也可以将位置参数固定为零，看看当前人工过程是否真的需要更细的位置表达。记录模型参数量、训练耗时和每个种子的误差范围，避免只保留最有利的一次。这个小样例的任务是教会实现和审查结构，不是展示注意力天然优于简单模型。

## 练习
1. 本课一个 token 代表什么？
2. 因果掩码能阻止全样本标准化泄漏吗？
3. 为什么最后位置可以访问全部窗口？
4. 改最后 token 的检查为什么要使用 eval？

## 参考答案
1. 一个已完成历史观察时点，特征经线性层映射到八维。
2. 不能，泄漏发生在网络输入生成前。
3. 这些都在当前决策时已知，预测目标在窗口之后。
4. 避免随机层使两次输出差异混入掩码检验。
