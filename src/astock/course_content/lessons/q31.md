# 布林带均值回归：便宜可能继续变便宜

## 从指标转成假设
布林带下轨只是某个滚动均值减去若干倍滚动标准差。价格低于下轨，说明它相对于这个窗口偏低，不等于公司便宜，也不等于下一天一定反弹。均值回归策略额外假设这种偏离有机会回到某个中心。本课用收盘价格回到滚动均值作为退出条件，同时设置单独的收盘止损信号。

与趋势策略相比，均值回归经常表现为多数小收益与少数较大损失。若只看胜率，很容易忽略最后一次下跌吞掉此前收益。建立规则前，先写下最不希望遇到的行情：持续单边下跌、价格跳空、交易受限以及窗口均值本身快速下移。

## 入场后发生什么
state 保存是否处于持仓目标，entry 保存本次入场信号价格。价格回到当前均值，或低于信号价格的 90%，就产生退出目标。这里用信号价计算阈值只是独立规则演示；真实账户应从订单回报取得实际成交价，并处理部分成交后的平均成本。信号价和成交价之间可能有跳空，不能把它们混用。

程序先判断退出，再判断空仓入场，而且使用 elif，防止同一根行情退出后又立即重进。没有这个约束，强烈下跌时可能同时符合止损和低于下轨条件，从而发出互相冲突的动作。是否允许当日重新进入应由策略明文决定，并受证券交易制度限制。

## 如何迁移到 AStock
先在练习区核对表格数值，再复制自己的模型副本。用 ctx.history 得到价格窗口，按相同 ddof 计算均值和标准差；numpy 返回值写入 ctx.explain 前转成 Python float。检查 ctx.has_open_orders，确认持仓为空后才发买单。退出使用实际 available 数量。日线收盘条件要等待后续行情执行，不能声称在止损阈值精确成交。

本课不把目标序列转换为收益，因为仅有信号价格还缺少完整执行模型。到第 37—39 课会独立核算现金与委托，届时应把这份信号函数作为输入，而不是改变它来配合更好看的结果。

## 参数实验与失败证据
首先把带宽从一倍改为两倍，其他条件不动。记录入场数量是否减少，以及那些被过滤的机会后来发生了什么。其次保持带宽，改变止损阈值。更紧止损可能减少一次亏损，也可能把本来会回归的交易提前切掉。最后删除止损分支，比较持续下跌段的持仓目标；只观察暴露差异，不凭缺少撮合的数组报告收益。

再构造一段价格每天缓慢下跌的序列。即使每次下轨信号都“看起来很便宜”，滚动均值也在跟着下移。将回归基准设为入场时固定均值与每期更新均值，会得到不同退出路径。两种假设都可以研究，但必须在回测前定下来。

## 常见实现错误
第一，直接用低于下轨的布尔序列当持仓，一旦价格回到轨道内就退出，实际规则变了。第二，历史不足时把标准差 NaN 填零，导致过早信号。第三，用账户总持仓推断本策略独立持仓，却混入其他策略人工操作。第四，遇到亏损才追加止损参数，再拿同一段数据宣称改进有效。


## 案例复盘：止损后立刻又出现低位信号

假设第一次入场参考为 8，之后价格继续下跌。达到退出条件后，价格往往仍低于新的布林下轨，下一次观察可能再次满足入场。若没有再入场约束，策略会在持续下跌中反复小亏，而不是只亏一次。添加冷却期、趋势过滤或要求先回到轨道内再重新跌破，都是可研究的改动，但都要单独比较。

不要直接把每次失败解释为“参数还不够好”。先统计下跌阶段的候选数量、实际持仓时长和累计费用。如果一次趋势性下跌制造了十次看似独立的信号，它们并不是十个完全独立的机会；它们共享同一个不利市场状态。用普通胜率置信直觉可能高估证据数量。

检查标准差变大的作用。剧烈下跌后带宽会扩大，可能使后续价格不再低于下轨；这并不说明风险消失，只说明阈值也在变化。将下轨、价格、滚动均值与入场状态一起打印，才能分清是价格回升还是阈值下降导致条件改变。

在报告中为“回归成功”“成本退出”“样本结束仍持有”分别列出记录。样本结束时尚未离开的亏损仓位不能被排除在胜率之外；账户权益应按统一口径估值。若只统计已经平仓的交易，最后一笔持续亏损可能被藏起来。


## 两个均值的选择会改变退出逻辑

入场时把均值固定下来，意味着你期待价格回到那一次偏离之前的中心。每期更新均值，意味着中心也跟随新数据改变。假设入场后价格继续下跌，滚动均值逐步下降，某天价格仅略微反弹就可能达到新均值并退出；固定旧均值版本可能仍在等待。两者没有脱离数据的绝对优劣，但收益和持有时间会不同。

请在同一入场序列上只改变退出基准，记录每次退出理由。若固定均值长期不达标，风险约束应如何处理？若滚动均值下降使退出更容易，它究竟是在捕捉反弹，还是接受更小亏损？这些问题要通过账户结果回答。

在比较标准差倍数时也别忘记分布假设。价格低于两倍标准差带，不能机械等同于正态分布中某个固定概率事件。价格水平、滚动窗口和市场变化都不满足简单独立样本的理想条件。下轨在这里是可计算的阈值，不是概率保证。

## 参考答案

1. 因为退出条件是回到均值或止损，state 需要持续保存。
2. 不同。真实资金风险应从实际成交价和可执行退出条件计算。
3. 只能说触发更少；单次损失、持仓时间和极端行情暴露仍需检验。
