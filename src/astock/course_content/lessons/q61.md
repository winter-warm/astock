# PyTorch 最小训练流程：把理论写成可运行的循环

## 先拿一个答案已知的问题检查工具
你已经知道 MLP 和 attention 的基本思想，这一模块的重点是让实现和研究边界真正落地。第一课不急着预测市场，而是用人工关系 y=2x+1 检查张量、梯度与优化器。如果连已知答案的小问题都学不好，直接换成金融数据只会让错误更难定位。

本例在 CPU 上训练一个单输入、单输出线性层。它不是完整 MLP，却已经包含神经网络训练所需的核心步骤。后面增加隐藏层或换成序列模型，训练循环的职责基本不变。

## 张量形状是第一个接口
x 的形状为 100×1，表示一百个样本，每个样本一个特征；y 也为 100×1。nn.Linear(1,1) 接收最后一维长度为一的输入并输出同形状预测。将 y 写成长度 100 的一维向量时，某些操作可能广播成错误的二维比较，而不是按样本一一计算误差。因此后续课程会不断断言 prediction.shape 与 target.shape 完全一致。

数据类型也需要明确。此例由 torch.linspace 创建浮点张量；真实 CSV 读入后可能得到整数、双精度浮点或对象类型，必须在数据边界转为模型需要的 dtype。不要通过随处强制转换掩盖缺失字符串等输入问题。

## 核对可预期的结果
训练后权重应接近 2，偏置接近 1，x=0.5 时输出接近 2。断言使用容差，不要求浮点数与数学答案逐位相同。损失应显著下降，这里可以合理地设定下降测试，因为数据关系完全由我们构造、模型也足以表达它；这与对真实市场收益设“必须盈利”的测试不同。

如果断言失败，先检查学习率、形状、是否清梯度、是否调用 step，再检查随机种子。不要先增加层数或换更复杂优化器。一个简单可解释例子应当帮助缩小错误范围。

## train、eval 与 no_grad 不可混用理解
model.eval() 切换某些层的行为，例如 dropout 和批归一化；当前单线性层没有这些差异，但保持习惯有助于后续网络。no_grad 则关闭梯度记录，适合纯预测。两者处理的问题不同：eval 不会自动关闭梯度，no_grad 也不会自动把 dropout 切成评价状态。

本例只展示训练拟合，没有独立泛化结论。它的价值是代码流程可核对。真正金融模型仍需时间划分、训练段预处理、验证选轮数和独立测试；你不能因为线性玩具问题的训练损失很低，就跳过这些步骤。

## 学习率实验
把学习率从 0.1 改成 0.001，运行同样轮数，观察下降是否更慢。再尝试一个很大的学习率，例如 3，损失可能振荡或发散。保存曲线，不只看最后一个数字。发散时先回到已知稳定的参数，而不是继续延长训练。

另一个实验是省略 zero_grad，记录权重与损失变化，再恢复正确代码。这是一个有意引入的错误练习；不要把累计梯度版本误保存为参考答案。通过小实验理解状态，比背一段固定训练模板更可靠。

## CPU 与复现
设置单线程减少小模型在不同机器上的线程调度差异，也避免课堂样例占满所有核心。固定随机种子使初始化可重复，但不保证所有平台和库版本逐位一致。正式记录还要保存 Python、PyTorch 和依赖版本；本课程 Notebook 包提供锁文件，目的就在于减少环境差异。

模型很小，不需要下载预训练权重，也不需要 GPU。之后的 MLP、LSTM 和 Transformer 同样采用小规模 CPU 样例，让你先验证数据与代码，再决定是否值得扩大计算。

## 用手算的一步理解梯度与学习率
把样本暂时缩小成两个点：输入分别为零和一，目标分别为一和三。假设当前权重和偏置均为零，则预测均为零，平均平方误差为五。对权重的梯度为负三，对偏置的梯度为负四。学习率为零点一时，一次更新后权重变成零点三、偏置变成零点四，两次预测变成零点四和零点七，误差已经下降。你可以在纸上完成这一过程，再用自动求导核对；自动求导节省的是求导与链式传播的工作，不会替你判断目标列是否放对。

这个两点例子还解释了为什么不能把学习率当作越大越好。参数沿负梯度方向走很远，可能跨过低误差区域，落到另一侧更高的位置。损失是平方项，离最优点越远梯度通常越大，下一步又可能跨得更远。观察曲线时，持续下降却很慢与反复爆炸是不同问题，前者可能需要更多轮数或适当增大学习率，后者首先需要缩小步长并检查数据尺度。

实际一百点脚本在固定设置下学到的权重约为一点九九九四，偏置约为一，预测零点五约为二。不要把这些末位小数当成跨机器标准答案；真正要检查的是参数接近已知生成关系、预测维度正确、损失有限且下降。若换成带噪声目标，最后损失不会降到零，原来很严格的拟合断言也需要改成与实验目的相符的检查。

再做一个形状排错实验：把目标从一百行一列压成长度一百，让它与一百行一列的预测相减。广播可能产生一百行一百列的误差矩阵，含义变成每个预测与每个目标比较。代码有数值输出，优化器也会更新，但所学任务已经错误。先打印输入、预测、目标和误差的形状，再断言形状相同，是比盯着损失小数更早发现问题的办法。

最后区分一次实验中的三个状态：模型参数、优化器内部状态、随机数发生器状态。只保存模型权重足够进行预测，却不一定足够从中断位置精确继续训练。入门练习可以每次重头运行；长期实验若需要恢复训练，应一并记录轮数、优化器状态、随机种子与预处理配置。
