## 文件路径不是你想象中的位置
相对路径按进程当前工作目录解释，不一定按源码所在目录解释。在 AStock 的课程练习区，每次运行进入一个新的练习目录，因此 prices.csv 会写入该次尝试的目录，不会覆盖你的历史行情文件。外部 Notebook 也应先检查工作目录，再开始读取数据。

处理路径用 pathlib，避免把反斜杠和转义字符写错。跨机器分享项目时，把输入数据放在项目目录内，并从确定的项目根目录构造路径。不要把自己的绝对磁盘位置写进课程答案。

## UTF-8 与换行
中文文本显式指定 encoding='utf-8'，让源码、CSV 和报告拥有一致编码。Windows 下 csv 文件使用 newline=''，把换行处理交给 csv 模块。不能通过反复尝试编码并忽略错误来“修好”金融数据；丢掉的字符可能正是证券标识或负号。

## 导入模块与运行环境
import csv 使用 Python 标准库；import pandas 依赖当前 Python 环境已安装的第三方包。电脑里有多个 Python 时，安装成功与运行成功可能发生在不同环境中。外部课程使用 uv 项目固定依赖，执行时从项目目录使用 uv run，避免把某个全局环境当作课程环境。

不要把脚本命名成 csv.py、numpy.py 或 pandas.py。当前目录中的同名文件可能遮蔽真实模块，使报错看起来像第三方库损坏。先看 traceback 中实际加载的文件路径，再决定如何修复。

## 可重复运行
一个可靠实验应能从空环境状态开始运行。Notebook 中先手工执行后面的单元格，再回到前面补变量，容易隐藏依赖。完成一份 Notebook 后重启内核并从上到下运行，才能发现执行顺序问题。课程练习区每次新进程的设计也在帮助暴露这种错误。
