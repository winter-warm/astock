# 函数、类与策略回调

## 从普通函数到持续接收数据
C++ 中你可能习惯在 main 里编写循环。事件驱动策略把循环交给框架：框架收到行情后调用你的方法。你的职责是维护必要状态，并在当前已知数据范围内产生动作。AStock 的 initialize 只负责初始化；on_bar、on_quote 和 on_order 分别接收完成的 K 线、快照和订单事件。

普通 Python 方法的第一个参数 self 指当前实例，作用可类比理解 this，但它会显式写在参数列表中。调用 a.update(price) 时不用再传入 a。实例属性应在初始化时建立，不能让几个策略账户意外共享一个可变列表。

## 历史不足时为什么返回 None
三期均线至少需要三个观察值。返回 None 表示结果尚不可计算，比返回 0 更清楚。价格大于零并不意味着“价格高于零均线”就是有效交易信号。使用者必须先检查结果是否为 None，再作比较。这里应使用 is None，它判断特殊空值身份，而不是把 0、空列表和 None 混为一类。

第 3 个价格到来时，窗口为 10、11、12，均值 11。第 4 个价格到来时，窗口变成 11、12、9，均值 32/3。输出的长小数是浮点表示的正常现象，做数值测试时通常使用容差，而不是对任意复杂浮点结果要求逐位相同。

## 参数与状态分开
period 是控制行为的参数，values 是运行过程中累积的状态。把两者混在一起会使复现实验困难。每次新实验应从清楚的初始状态开始；改变 period 后沿用旧的 values 是否合理，需要明确约定。AStock 用独立账户记录每次运行，课程练习区也每次创建全新的进程。

避免用 def f(values=[]) 这样的可变默认参数保存每次调用独立的数据。默认对象在函数定义时创建，后续调用可能共享它。需要每次新列表时，用 None 作为默认值，再在函数内部创建列表。

## 异常如何帮助研究
周期小于 1 时主动抛出 ValueError，能在错误参数进入计算之前停止。异常信息应说明哪个约束被破坏，而不是只输出“错误”。不要用一个捕获所有异常并继续交易的 try/except，把数据错误变成正常信号。框架停止一份异常策略，比悄悄产生不可解释的委托更容易核查。
