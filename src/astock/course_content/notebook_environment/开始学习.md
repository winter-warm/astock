# 在本机运行课程 Notebook

本目录是独立课程副本。它不修改 AStock 的安装环境，也不连接券商账户。每次从软件导出都会创建新目录，不覆盖你已修改的笔记。

1. 将目录放在自己可写的位置。保留 `.python-version`、`pyproject.toml`、`uv.lock` 和 examples 文件夹。
2. 若没有 uv，按官方安装说明 https://docs.astral.sh/uv/getting-started/installation/ 安装；随后重新打开 PowerShell 7，让 PATH 生效。
3. 在本目录打开 PowerShell 7，运行 `./Start-Notebook.ps1`。首次需要联网安装 Python 3.12 和依赖，包括 CPU 版 PyTorch；依赖安装完成后的合成数据实验可离线运行。
4. 浏览器打开 JupyterLab 后，双击对应 qXX.ipynb。代码由课程原始样例生成，章节和代码在同一份笔记中。
5. 从第一格开始执行，读输出后再进入下一格。修改参数前保留原输出。完成后使用“Restart Kernel and Run All Cells”从空内核重跑，检查是否依赖之前手工创建的变量。
6. 保存笔记。在 AStock 中打开或导出笔记不代表练习通过；外部成果应保留为自己的研究记录。

若浏览器没自动打开，复制终端显示的本机地址访问。只在本机使用，不把含 token 的地址发给他人。关闭浏览器不一定关闭服务，结束时在启动终端按 Ctrl+C。

## 出错时检查

- 找不到模块：确认使用本目录项目内核，先重新执行启动脚本；不要向 AStock 的 `_internal` 安装包。
- 路径不存在：Notebook 的工作目录应是本目录。examples 保存完整脚本，附带的数据和图像保持原相对目录。
- 内核忙：先中断执行；无限循环必须修改代码，反复重启不会使逻辑变正确。
- AI 实例：默认使用明确标注的离线流程演练。只有按对应课配置模型地址和主动启用真实调用时才联网；不要把密钥写进 Notebook 或输出结果。
- 安装失败：保留原始错误信息和失败包名。网络失败不会自动改用另一套未锁定依赖。

课程数据和结果用于理解研究方法。合成样本的拟合效果不是策略盈利证据；真实数据路径须按正文核对获取时间、可用时点和交易约束。
