# 怎样把这 72 课学成一段长期课程

你已经做过股票交易，也学过 C++ 和数据结构，所以前六课集中处理研究方法、Python 与 C++ 的差别，以及 AStock 回调接口。无需重新练习开户、普通下单或循环语法。后面则从没学过技术指标的起点讲起：先看懂量的含义，再手算，再写代码，最后检查执行与风险。

## 每课怎样学

第一遍阅读问题和小数据，暂时不运行代码。把输入、输出、时间单位写在纸上，手算正文给出的一个位置。第二遍运行原始示例，逐项对照结果。第三遍只改一个参数或一组数据，先预测结果再运行。最后做练习与知识自测，核对参考答案，并留下一个仍不理解的问题。

一课可以分成两次学习。遇到一个公式不熟，不必把整门统计课学完再回来；先理解本例中每个符号对应哪列数据、怎样算出一个数，再沿参考链接补充背景。每周留下半次学习时间整理错误，比连续读完更多标题更有用。

## 建议节奏

| 阶段 | 课程 | 可交付的小成果 |
| --- | --- | --- |
| 第 1 周 | 01—06 | 把一条交易想法改为确定规则，保存一份能解释回调的策略副本 |
| 第 2—4 周 | 07—18 | 从小表计算收益、滚动特征、净值和回撤，逐行核对时间对齐 |
| 第 5—7 周 | 19—28 | 解释 K 线、均线、MACD、RSI 等指标的单位、窗口与失败情形 |
| 第 8—10 周 | 29—42 | 比较趋势、突破和均值回归；写最小账本并用实际引擎核验订单 |
| 第 11—13 周 | 43—54 | 写出仓位上限、组合规则与因子评价表，解释成本和截面排序 |
| 第 14—17 周 | 55—66 | 用训练/验证/测试流程比较线性、树和小型深度模型 |
| 第 18—20 周 | 67—72 | 做离线 AI 研究流程，形成能重新运行的毕业研究报告 |

这是可调整的节奏，不是解锁限制。指标和回测章节可以多停留；模型课若发现数据时间仍没对齐，应回看 10—12 与 37—41 课。机器学习复杂度不能补救泄漏的数据。

## 三种代码入口

“软件内 Python”适合数组、表格、指标和小型回测计算，使用独立进程，有停止与超时。示例可通过 `lab.table` 和 `lab.lines` 提交结果表和曲线。每次运行有新工作目录，跨次需要的文件应明确保存位置。

“策略编辑器”示例实现 AStock 的 UserStrategy。载入教学副本后选择数据、设置费用，再让真实引擎产生委托和成交。这些示例在导出的 Notebook 中以代码说明展示，不把策略类定义成功当作引擎实作完成。

“外部 Notebook”用于 Backtrader、机器学习和 CPU 深度学习。软件可以导出本课或全部课程，独立环境由 uv.lock 锁定。代码以正文引用的资源文件为唯一来源；修改自己的笔记不覆盖软件课程。外部完成记录保存在笔记中，阅读记录、知识自测与代码运行分别保存。

## 怎样判断自己可以进入下一阶段

完成指标部分时，应能说明一个指标什么时候可知、缺少历史时输出什么、它在哪种行情里容易失效。完成回测部分时，应能由现金和持仓复算权益，并解释信号与成交之间的时间差。完成模型部分时，应能指出训练器、缩放器和参数选择各看过哪些数据，解释为什么测试段不能反复用于调参。

毕业项目可以得到负结果。提交完整数据定义、代码、配置、对照实验和失败解释，比只提交一张上升曲线更有研究价值。所有默认样例使用明确的人工数据；它们证明实现与推导是否一致，不证明真实市场盈利。

## 参考材料怎样配合

- [腾讯云 Backtrader 教程清单](https://cloud.tencent.com/developer/inventory/6211/article/1388272)适合对照数据源、策略、指标、分析器和回测组织方式。本课程第 42 课另外提供小型可执行对照，接口细节以 [Backtrader 官方文档](https://www.backtrader.com/docu/)核对。
- 《Python量化投资基础教程》作为中文入门参考。这里仅核对了[高等教育出版社公开书目](https://xuanshu.hep.com.cn/front/h5Mobile/bookDetails?bookId=601eeecf966feeeca7333ed2)，没有把未获得的全书内容说成已读，也没有复制它的正文。
- [菜鸟 Python 量化教程入口](https://www.runoob.com/python-qt/qt-tutorial.html)保留为用户提供的补充阅读入口。本次访问返回 403，未把无法核验的页面内容用作代码依据。
- [Machine Learning for Trading 第三版作者课程目录](https://ml4trading.io/third-edition/chapters/)提供从数据、特征到模型、策略与生产运行的完整研究视角。本课程选取适合个人学习的路线，以小型 CPU 实验说明方法，没有复刻其全书或声称覆盖全部生产系统。
- [NVIDIA 多智能体信号研究案例](https://developer.nvidia.com/blog/automating-and-optimizing-financial-signal-discovery-with-multi-agent-systems/)用于理解假设、代码、评价的分工。第 67—72 课使用可离线运行的小型流程，并将真实模型连接单独显式开启；流程自动化不等于信号已经有效。

各课末尾另外列出 Python、pandas、scikit-learn、PyTorch 等一手接口来源。课程正文和教学数据为本项目编写，参考链接用于继续学习和核对。
