# 写策略到一次回测

1. 打开应用即进入写策略；中央为 Python 源码，右侧为参数和回测准备。
2. 点击新建策略并填写名称，或通过模板与已存策略选择已有版本。需要保留另一版本时先另存副本。
3. 在源码区编辑 UserStrategy；修改 PARAMETERS 声明后在右侧参数设置点击检查参数，核对下方字段与实际数值。
4. 点击保存或按 Ctrl+S。保存只说明源码和参数存储成功，不代表策略已经正确执行。
5. 点击去回测会将当前草稿和参数选为待运行策略。核对顶部策略名与来源，再检查数据、区间、基准、本金和费用，最后点击开始回测。
6. 完成后查看净值、回撤和成交记录，先核对运行依据，再解释策略结果。

## 接口与数据

initialize 初始化；on_bar 处理 K 线；on_quote 处理快照；on_order 收到委托状态变化。ctx.history 返回价格列表，最多 2048 个观察值，并非 OHLCV 表。需要高低价和量时，在 on_bar 中按证券缓存实际收到的 bar 字段。点击“策略接口”打开独立的只读速查窗口，查看本软件支持的方法、参数和调用时机。窗口可保持打开供编辑时对照，关闭后仍留在写策略页面，草稿和参数不会改变。

## 保存与切页

写策略是主工作区，不是另外弹出的编辑器。切换页面会保留草稿，不自动保存或启动。需要持久保存时点击保存，需要查看其他策略时打开模板与已存策略。

没有订单时检查历史长度、条件和资金；提交了订单却未成交时查看状态理由、限价和规则；Python 报错时先看自己的源码行号。
