# 名称输入、文件选择与确认窗口

## 新建模型与另存副本

在模型研究点击“新建 Python 模型”，或在编辑器点击“另存副本”，会出现模型名称输入框。先输入一个能区分实验的名称，例如“均线窗口三期_费用实验”。点击确定提交；取消或 Esc 返回。空白名称不会创建模型，已有名称会提示冲突，请换名称后重试。

确认有效新名称后，软件先保存当前模型，再建立新模型或副本。它不是“放弃当前草稿”的操作。独立编辑器的关闭和“返回模型列表”同样会保存代码；若想比较修改前后，应该先建立副本。输入框里按 F1 可查看名称输入说明。

## 导入 Python 模型

点击“导入模型”或 Ctrl+O，在系统文件选择器的地址栏输入文件夹位置，或用左侧导航找到文件。选中 `.py` 文件后，核对下方文件名，点击打开；取消返回，不导入。源码按 UTF-8 读取，只选择自己信任的代码。

导入之后还要检查类、回调和 PARAMETERS，再保存自己的副本。文件选择成功只代表找到了文件，并不代表接口正确，更不代表运行已通过。路径包含中文或空格时，使用文件选择器即可，不需要手工给文件名加引号。

## 导入行情数据包

在数据中心点击“导入数据包”，选择数据包的 JSON 元数据文件。保留它引用的配套 Parquet 等文件及原有相对位置；不要只复制 JSON 后期待数据自动出现。点击打开后回到软件观察校验状态，必要时用“取消数据导入”停止当前任务。

完整校验成功的数据才加入数据中心。同编号不会直接覆盖原数据；字段、规则、权益或文件引用存在问题时，按具体错误修复数据包再导入。系统文件窗口的“打开”与应用中的“使用所选数据”是两步不同操作：前者选择要导入的文件，后者选择下一次研究使用的已保存版本。

## 导出源码

编辑器点击“导出源码”，在系统保存窗口选择一个可写目录并填写 `.py` 文件名。保存到已有路径时，先检查系统的覆盖确认；若要保留旧版本，取消覆盖并改用新名称。导出的源码不包含账户、完整行情或所有运行证据，复盘还需保存运行报告。

Notebook 导出不使用覆盖旧文件的系统保存对话框：软件每次建立一个独立目录。点击“打开导出目录”后可在文件管理器复制整个目录，再用其中的启动脚本进入 Jupyter。

## 错误与替换确认

“需要处理”窗口包含具体失败原因，先读正文，再点确定关闭提示。关闭提示不等于修复错误；返回相关表单或日志处理后再执行。遇到源码行号，应在编辑器跳到对应行核对缩进、变量名和接口。

课程中的“还原本课示例”会询问是否替换草稿。选择是才将当前示例的草稿替换为发行版原始代码；选择否或关闭确认框则保留草稿。其他示例草稿单独保存，不受这次还原影响。

Windows 文件选择器外观随系统版本和个人设置变化，地址栏、文件名、打开/保存与取消承担上述职责。软件帮助不会代你确认覆盖、保存或执行业务操作。
