# 虚拟手动交易：报价、委托、撤单与停止

这份任务清单是离线核对资料。首次操作引导统一从「帮助 → 使用教程重放」进入，不自动执行业务动作。

## 1. 选择在线证券

位置：数据中心 → 证券搜索 / 添加自选

按代码或名称搜索，选中行后加入在线标的。可多选，最多 20 个；修改在线列表后需要重新连接。

完成后核对：工作台在线代码列表包含正确交易所后缀，没有重复项。

## 2. 连接并核对报价

位置：模拟交易 → 连接行情

点击连接，核对行情时间与年龄。休市可选择教学快照进行回放；不要把离线数据当作实时连接成功。

完成后核对：报价有效且新鲜；已连接并不表示已经创建账户或启动策略。

## 3. 建立手动账户

位置：模拟交易 → 手动练习 → 建立练习账户

核对证券与虚拟资金后点击建立，等待规则准备完成。该账户与自动策略账户分开。

完成后核对：当前账户明确为手动练习；准备失败时没有半成品账户。

## 4. 填写委托

位置：手动练习 → 代码 / 方向 / 数量 / 限价

数量为股或份额，价格是买入最高价或卖出最低价。可点击取对手价辅助填写，提交前再核对新鲜度、买入单位和可卖数量。

完成后核对：参数与所选账户一致；持有数量不自动等于可卖数量。

## 5. 提交并核对结果

位置：手动练习 → 提交模拟委托

点击一次提交，再到委托表查看等待、部分成交、已成交或拒绝。不要因未立即成交重复提交相同指令。

完成后核对：每笔委托有自己的状态和理由，资金冻结随执行变化。

## 6. 撤销或停止

位置：账户与执行 → 选中委托 → 撤销选中委托；或顶部停止并撤单

撤单前核对订单编号与账户；已成交部分无法撤回。结束整个账户使用停止并撤单，再确认剩余委托和冻结资金。

完成后核对：未成交余额被撤销；历史成交与结果仍可查看。
