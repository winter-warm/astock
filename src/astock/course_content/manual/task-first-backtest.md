# 第一次离线回测：策略 → 数据 → 运行 → 结果

这份任务清单是离线核对资料。首次操作引导统一从「帮助 → 使用教程重放」进入，不自动执行业务动作。

## 1. 准备离线数据

位置：左侧数据中心 → 数据管理窗口

单击合成教学日线数据行，阅读右侧来源、覆盖与权益说明。日线用于历史回测，快照用于回放。

完成后核对：选中行与详情是同一数据；明确标记为合成教学行情。

## 2. 使用数据

位置：数据中心 → 使用所选数据

核对行后点击使用所选数据。窗口关闭后检查工作台数据下拉框；这一步不会开始交易。

完成后核对：工作台显示所选名称，预览加载完成。若仍在加载，可等待或取消预览。

## 3. 选择研究模型

位置：写策略 → 模板与已存策略 → 选择模板

从选择窗口载入教学模板，返回写策略页面检查源码和参数。修改前可另存副本并输入新名称。

完成后核对：写策略页面显示所选名称；保存后副本可从模板与已存策略中找到。

## 4. 设置日期和基准

位置：左侧历史回测 → 回测设置

点击写策略页的去回测，当前草稿和参数成为待运行策略；先核对顶部名称与来源，再打开回测设置，核对区间、基准和本金。保存设置不会启动回测。

完成后核对：日期在数据覆盖范围内，开始不晚于结束；界面显示本次区间。

## 5. 核对费用并启动

位置：写策略 → 右侧回测参数；随后历史回测 → 开始回测

在写策略右侧核对佣金万分数、最低佣金元、滑点价格单位与参与率，再去回测并点击开始回测。每次新建独立账户，不继续旧结果。需要暂停或单步才勾选展开运行控制。

完成后核对：账户状态由准备变为运行，时刻向前推进；错误时先阅读日志而非重复启动。

## 6. 检查订单和成交

位置：历史回测 → 操作记录 → 下单与状态 / 成交明细

对照委托时间、成交时间、证券、方向、数量与费用。选中成交行在图上定位，查看理由；委托被接受不等于已经成交。

完成后核对：成交记录与图上标记对应；未成交和拒绝能在委托状态中解释。

## 7. 阅读绩效

位置：历史回测 → 净值与回撤

同时看收益、最大回撤、费用与成交数，再看基准。不要只凭曲线上升判断策略有效。完成后可导出报告记录本次依据。 导出报告与运行对比统一从账户与记录进入。

完成后核对：观察截至时刻、数据及费用与研究记录一致；完成状态不代表策略在真实市场盈利。
