# 长期学习：阅读、练习、自测与 Notebook

这份任务清单是离线核对资料。首次操作引导统一从「帮助 → 使用教程重放」进入，不自动执行业务动作。

## 1. 找到课程

位置：左侧量化课程

输入术语或课名搜索，选中目录条目。只看书签可进一步筛选，清空搜索并取消书签筛选恢复所有条目。

完成后核对：正文标题和目录一致；可以按模块顺序学习或回看先修内容。

## 2. 先读后练

位置：阅读器 → 本课目录 / 显示练习答案

从目录跳到概念、手算、代码或练习。先独立作答，再勾选显示练习答案；标记已读仅记录阅读。

完成后核对：能解释公式中的每个量和示例数据的单位。

## 3. 运行基础代码

位置：Python 练习 → 示例选择 → 运行练习

选择标记为软件内 Python 的示例，修改一个参数后运行，比较输出、表格和曲线。停止只终止课程进程；每次运行工作目录独立。

完成后核对：输出与手算一致，成功运行不自动通过知识自测。

## 4. 知识自测

位置：本课知识自测 → 答案输入 → 检查答案

按题目要求输入数字或简短文字并检查。答对记录本版自测通过；代码运行和知识自测分开记录。

完成后核对：回答正确后有解释；正文或题目更新后需要重新核对。

## 5. 策略与进阶环境

位置：示例标签为策略编辑器或外部 Notebook

策略例点击载入策略教学副本后去编辑器检查数据再运行。进阶例导出 Notebook，打开目录，用 PowerShell 7 执行 Start-Notebook.ps1。可一次导出全部课程。

完成后核对：Notebook 使用独立锁定环境；首次安装需联网，AI 默认离线回放，真实接口需显式配置。
