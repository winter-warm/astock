# 导出、查报告与保存学习记录

进入“账户与记录”，先在选择器核对要导出的策略、模式和运行标识，再点击“导出所选报告”，开始后台导出。Ctrl+E 用于打开账户与记录，仍需选择并确认导出对象。报告以后台读取时的已保存快照为准；账户可以继续运行，因此报告观察截至时刻可能早于你随后看到的界面。切换账户不改变已经启动的导出对象。

成功后点击“打开报告”。HTML、成交 CSV、权益流水 CSV 和运行 JSON 保存在 data/reports 下的独立导出目录，每次导出不覆盖上一次。取消或关窗不发布未完成报告。需要最新状态时重新导出并比较观察时间。

## 长期课程
目录按模块排列，搜索同时匹配标题和已编写正文。字号按钮改变阅读大小；切换课程会保存阅读位置和代码草稿。上一节和下一节按当前可见目录移动。标记已读只记录阅读，不代替练习。

练习区的“运行练习”启动独立 Python 进程；每次运行有自己的工作目录。“停止”终止当前进程；超过 30 秒自动停止，输出过长会截断。源码错误显示行号。此处只执行可信本地代码，不是权限沙箱。

“还原本课示例”会询问是否覆盖当前草稿；复制代码复制的是练习区当前内容。运行成功只说明代码正常结束，没有自动证明答案正确。课程阅读、代码执行与知识自测分别记录，不互相替代。

## 内容更新
新版正文发生变化时，已读历史保留并提示复习。标为“待编写”的目录项还没有正式内容，不能标记完成，也不计作课程正文交付。

## 目录、书签和答案

本课目录下拉框跳转到文章标题；添加书签后可用“只看书签”快速筛选。正文区域和整个右侧面板各有滚动条：正文滚动用于长文，外层滚动用于小窗口中找到下方代码、自测。字号只改变正文，不改代码缩进。

默认隐藏标题中含“答案”“解析”的段落；勾选“显示练习答案”后展开。知识自测有独立答案输入框，按题目规定的单位和简短格式作答，检查正确后记录当前正文版本的通过状态。查看答案、标记已读和代码正常退出都不会自动通过知识自测。

## 导出 Notebook 与策略代码

示例选择器说明运行位置。软件内 Python 使用应用自带环境；策略例点击“载入策略教学副本”会先保存原模型，再生成新名称并打开编辑器，不自动运行。外部 Notebook 点击“导出本课 Notebook”或“导出全部课程 Notebook”，每次创建一个新目录，包含原始正文、同源代码、uv.lock 和启动脚本，不覆盖旧笔记。

点击“打开导出目录”，在该目录中用 PowerShell 7 执行 `./Start-Notebook.ps1`。首次需要联网安装 uv 锁定依赖；已有依赖后可离线执行教学样本。不要把 Jupyter 或 PyTorch 装进便携程序的 `_internal`。高级 AI 示例默认为标注清楚的离线回放；只有你自行配置并显式启用连接时才调用真实服务。
