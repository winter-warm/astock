# 结果复盘：成交定位、运行对比和报告

这份任务清单是离线核对资料。首次操作引导统一从「帮助 → 使用教程重放」进入，不自动执行业务动作。

## 1. 选中历史运行

位置：账户与记录 → 账户选择 → 在所属工作区查看

在归档中选择要检查的运行，核对策略名、模式、状态和观察时刻。点击在所属工作区查看，回测进入历史回测，实时与手动账户进入模拟交易；查看不会重新执行。

完成后核对：图表、持仓与成交列表属于同一个运行。

## 2. 定位成交

位置：历史回测 → 操作记录 → 成交明细 → 单击一行

核对时间、成交价、费用和买卖理由，图表定位后可放大局部。返回最新行情解除固定定位。

完成后核对：图上证券和时间对应所选成交，不把局部视图误认作全部数据。

## 3. 比较运行

位置：账户与记录 → 运行对比

比较前核对数据、费用、规则、本金、引擎版本与观察时点。依据不同的结果不能直接按收益给策略排名。

完成后核对：比较表说明依据，失败运行不被当作零收益正常样本。

## 4. 导出报告

位置：账户与记录 → 选择账户 → 导出所选报告

导出绑定点击时的账户，以后台读取时已保存的快照为准。等待成功后打开报告；取消不发布未完成报告。

完成后核对：报告目录包含 HTML、CSV 和 JSON；观察截至时刻与本次复盘一致。
