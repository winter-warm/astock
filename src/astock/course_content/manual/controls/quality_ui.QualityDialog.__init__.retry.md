# 重新检查

## 在哪里

数据缺口检查。可在目标控件获得焦点后按 F1，或按 Shift+F1 再点选它查看说明。

## 用途与操作

对当前数据重新执行交易日和分钟缺口检查。任务在后台进行，可取消；不会填造价格，结果与报告展示实际覆盖。

## 完成后核对

先核对当前页面的对象与状态，再按上述说明操作；完成后检查结果提示或相应记录。

## 不可用或未出现时

检查进行中禁用重复开始；讲解预览中始终禁用。实际检查完成或取消后可重新检查。

隐藏的面板可从“视图”菜单显示；独立窗口的控件需要先进入该窗口。讲解不代点击业务按钮，关闭讲解不停止当前策略。
