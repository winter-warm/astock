# 按证券最小价格单位向不利方向调整模拟成交价格

## 在哪里

写策略 → 右侧基本信息、参数设置或回测参数；检查参数位于参数设置内。可在目标控件获得焦点后按 F1，或按 Shift+F1 再点选它查看说明。

## 用途与操作

按证券最小价格单位向不利方向调整模拟成交价格。数值 1 不是统一的 1 元。 先核对证券价格单位，再比较 1 与 3 的结果。增加滑点不能绕过委托限价。

## 完成后核对

先核对当前页面的对象与状态，再按上述说明操作；完成后检查结果提示或相应记录。

## 不可用或未出现时

若控件未出现，请按“在哪里”进入对应页面或展开视图面板；若当前不可用，核对当前选择与页面错误提示。不会因按钮灰色自动视为操作完成。

隐藏的面板可从“视图”菜单显示；独立窗口的控件需要先进入该窗口。讲解不代点击业务按钮，关闭讲解不停止当前策略。
