# 快照回放速度：1×按记录的报价间隔等待，5×等待原间隔的五分之一，单次最多等待60秒

## 在哪里

历史回测 → 展开运行控制；暂停、继续、单步与速度用于检查历史执行过程。可在目标控件获得焦点后按 F1，或按 Shift+F1 再点选它查看说明。

## 用途与操作

快照回放速度：1×按记录的报价间隔等待，5×等待原间隔的五分之一，单次最多等待60秒。仅改变回放节奏；K 线回测自动尽快计算，此项禁用，逐步观察请用暂停和下一时刻。

## 完成后核对

先核对当前页面的对象与状态，再按上述说明操作；完成后检查结果提示或相应记录。

## 不可用或未出现时

仅快照回放可调。当前有运行中或暂停的历史账户时，按该账户类型判断；K 线回测禁用。没有可控制账户时只设置下一次快照回放的预设。

隐藏的面板可从“视图”菜单显示；独立窗口的控件需要先进入该窗口。讲解不代点击业务按钮，关闭讲解不停止当前策略。
