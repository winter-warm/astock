# 停止并撤单

## 在哪里

历史回测 → 展开运行控制；暂停、继续、单步与速度用于检查历史执行过程。可在目标控件获得焦点后按 F1，或按 Shift+F1 再点选它查看说明。

## 用途与操作

结束当前选中运行并撤销剩余委托。核对账户后点击，再查看委托状态和冻结资金；停止不删除历史结果。

## 完成后核对

先核对当前页面的对象与状态，再按上述说明操作；完成后检查结果提示或相应记录。

## 不可用或未出现时

当前账户运行中或暂停时可停止并撤单；已结束账户不可再次停止。

隐藏的面板可从“视图”菜单显示；独立窗口的控件需要先进入该窗口。讲解不代点击业务按钮，关闭讲解不停止当前策略。
