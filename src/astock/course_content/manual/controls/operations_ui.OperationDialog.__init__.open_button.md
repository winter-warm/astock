# 成功后打开报告、查看选中运行或使用选中录制数据

## 在哪里

报告、对比与录制恢复。可在目标控件获得焦点后按 F1，或按 Shift+F1 再点选它查看说明。

## 用途与操作

成功后打开报告、查看选中运行或使用选中录制数据。按钮未启用表示结果尚不可用或没有有效选择，不能当作任务成功。

## 完成后核对

先核对当前页面的对象与状态，再按上述说明操作；完成后检查结果提示或相应记录。

## 不可用或未出现时

报告模式需导出成功；对比模式需选中没有读取错误的运行；恢复模式需选中已生成数据集的行。讲解预览始终禁用。

隐藏的面板可从“视图”菜单显示；独立窗口的控件需要先进入该窗口。讲解不代点击业务按钮，关闭讲解不停止当前策略。
