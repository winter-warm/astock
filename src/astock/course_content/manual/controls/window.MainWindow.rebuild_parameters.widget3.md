# 整数策略参数，由 PARAMETERS 中的 label、help、default、min、max 决定

## 在哪里

写策略 → 参数设置，先点击检查参数生成当前模型的字段。可在目标控件获得焦点后按 F1，或按 Shift+F1 再点选它查看说明。

## 用途与操作

整数策略参数，由 PARAMETERS 中的 label、help、default、min、max 决定。读本字段提示后输入范围内整数，单位随策略定义；保存后在新运行生效。

## 完成后核对

先核对当前页面的对象与状态，再按上述说明操作；完成后检查结果提示或相应记录。

## 不可用或未出现时

若控件未出现，请按“在哪里”进入对应页面或展开视图面板；若当前不可用，核对当前选择与页面错误提示。不会因按钮灰色自动视为操作完成。

隐藏的面板可从“视图”菜单显示；独立窗口的控件需要先进入该窗口。讲解不代点击业务按钮，关闭讲解不停止当前策略。
