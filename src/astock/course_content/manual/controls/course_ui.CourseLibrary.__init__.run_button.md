# 运行练习

## 在哪里

长期课程阅读器。可在目标控件获得焦点后按 F1，或按 Shift+F1 再点选它查看说明。

## 用途与操作

在独立 Python 进程运行当前草稿，使用新的练习工作目录。普通 Python 例可执行，策略和 Notebook 例需使用各自入口；正常结束不等于答案已验证。

## 完成后核对

先核对当前页面的对象与状态，再按上述说明操作；完成后检查结果提示或相应记录。

## 不可用或未出现时

只有软件内 Python 示例且没有正在运行的练习时启用。策略和 Notebook 标签需使用各自运行环境。

隐藏的面板可从“视图”菜单显示；独立窗口的控件需要先进入该窗口。讲解不代点击业务按钮，关闭讲解不停止当前策略。
