# 使用教程重放

## 在哪里

主窗口顶部文件、视图或帮助菜单，先展开再选择具体命令。可在目标控件获得焦点后按 F1，或按 Shift+F1 再点选它查看说明。

## 用途与操作

重放35步首次使用引导，也可通过章节选择直接查看写策略、数据与费用、回测准备、回测运行、读取结果、模拟交易、记录与课程。引导只切页与高亮，不保存草稿、不开始回测、不下单。可以随时结束。

## 完成后核对

先核对当前页面的对象与状态，再按上述说明操作；完成后检查结果提示或相应记录。

## 不可用或未出现时

若控件未出现，请按“在哪里”进入对应页面或展开视图面板；若当前不可用，核对当前选择与页面错误提示。不会因按钮灰色自动视为操作完成。

隐藏的面板可从“视图”菜单显示；独立窗口的控件需要先进入该窗口。讲解不代点击业务按钮，关闭讲解不停止当前策略。
