# 编辑策略：副本、参数、错误与保存

这份任务清单是离线核对资料。首次操作引导统一从「帮助 → 使用教程重放」进入，不自动执行业务动作。

## 1. 新建或打开

位置：写策略 → 新建策略，或模板与已存策略

新建时输入未使用的名称。已有模型若要保留原版，先另存副本；同名不直接覆盖。

完成后核对：写策略页面标题显示自己的策略名。

## 2. 编写源码

位置：写策略 → 中央源码区

在 PARAMETERS 中声明参数，在 UserStrategy 回调里编写规则。接口说明可查看函数列表。注意 history 返回价格序列，周期含义取决于输入数据。

完成后核对：源码没有引用不存在的接口；回调参数和缩进正确。

## 3. 重建参数表

位置：写策略 → 右侧参数设置 → 检查参数

修改 PARAMETERS 后点击检查参数。右侧会按声明生成整数、小数、开关和文字输入；再调整实际运行值。

完成后核对：表单标签、范围、默认值符合声明；报错时定位行号并修复。

## 4. 保存并试运行

位置：写策略 → 保存 → 去回测 → 开始回测

按 Ctrl+S 或点击保存，再去回测核对待运行策略、数据与区间。保存只说明源码与参数存储成功，点击开始回测才执行策略。

完成后核对：模型列表有已保存副本；实际运行日志能指出初始化和每个订单的原因。

## 5. 切换页面

位置：写策略 → 模板与已存策略

切换页面保留当前草稿，但不自动保存。需要存档时先点击保存；需要不同版本时另存副本。

完成后核对：回到写策略页面时草稿保持；保存后能在模板与已存策略中找到版本。
