# 手动练习与账户检查

1. 进入模拟交易的“普通交易 · 手动练习”标签，建立独立练习账户。
2. 核对所选账户，再填证券、买卖方向、数量和限价。
3. “取对手价”辅助填写价格，并考虑滑点；提交前再核对单位与方向。
4. 提交后在底部“委托”查看状态。提交成功表示订单进入流程，不是已经成交。
5. 部分成交时检查剩余数量；需要撤销时先选中对应委托，再点击撤销。
6. 在“成交”点选记录查看图表和原因；“持仓”区分持有与可卖数量。
7. “权益流水”查看分红登记、现金到账和新增份额可卖日期。

## 资金为什么暂时不能用
买单可能冻结现金；应收分红计入权益但尚未到账，因此不能用于下单。到账只是把应收变成现金，不再增加一次总权益。送转新增份额也可能尚未到可卖日期。不能只根据总权益判断一笔新订单有足够可用资金。

## 重启后的账户
正常退出撤销未成交委托；异常中断恢复时核对账本并取消旧委托。重启不自动执行策略。旧账户仅供查看，存在核对问题的账户会隔离保留证据，不应通过修改余额强行让它继续运行。
