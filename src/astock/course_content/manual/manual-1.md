# 安装、启动与备份

1. 完整解压 Windows 软件包，进入 AStock 文件夹。
2. 双击 AStock.exe。保留旁边的 _internal 文件夹，不能只移动 EXE。
3. 便携模式的数据保存在 EXE 旁的 data；源码启动可通过 --data-dir 指定目录。
4. 备份前退出软件，再复制完整 data 文件夹。它包含账户数据库、策略、数据、报告和新课程草稿。
5. 恢复到可写目录后启动；重启不会自动执行旧策略。

## 找不到数据时
先核对当前运行的是哪个软件目录，再看帮助菜单中的数据位置。不同启动入口可能使用不同的数据目录。不要因为某个新目录为空就删除旧目录。运行中的 SQLite 数据应先正常关闭后再复制，避免只复制主数据库而遗漏尚未合并的日志。

## 源码启动
项目使用 PowerShell 7 和 uv。安装包无需用户额外安装 Python；源码启动需要项目依赖。外部 Notebook 是另一套环境，不要把它的包安装到便携程序 _internal 中。
