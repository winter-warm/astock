# 准备历史数据：下载、检查覆盖、修订规则

这份任务清单是离线核对资料。首次操作引导统一从「帮助 → 使用教程重放」进入，不自动执行业务动作。

## 1. 打开下载表单

位置：左侧数据中心 → 数据管理窗口 → 下载历史行情

输入带交易所后缀的代码，可先用证券目录按名称核对。多个证券按表单格式分隔。

完成后核对：代码属于本次研究范围，未把名称当作代码提交。

## 2. 设置频率与来源

位置：历史下载窗口 → 周期 / 来源 / 起止日期

先选日线或分钟频率，再核对来源支持的范围。填写日期或点击最近天数预设，预设只填表，不下载。

完成后核对：来源、周期与日期能描述同一实验；分钟数据可能只能返回较短窗口。

## 3. 开始并等待

位置：历史下载窗口 → 开始下载

点击开始下载，在工作台观察进度。取消下载只终止本轮，原数据保留。失败时按提示改正输入或检查来源。

完成后核对：成功数据出现在数据中心；下载成功仍要检查覆盖和权益。

## 4. 检查覆盖

位置：数据中心选中数据 → 检查缺口

真实检查会立即启动后台任务。完成后点选缺口行阅读证券、时间和数量；需要全部区间时打开完整报告。检查失败先读错误，不以空表代替检查通过。

完成后核对：区分缺口、未覆盖和已知停牌，不能用前值填充来冒充真实行情。

## 5. 查看历史规则

位置：数据中心选中数据 → 证券规则

按证券添加有效日期区间并填写来源；股票状态建议先获取、预览再采用，ETF 当前资料不能直接覆盖全部历史。

完成后核对：区间有证据、不冲突，涨跌幅和可卖规则符合该证券与日期。

## 6. 另存并选新版本

位置：证券规则窗口 → 检查并另存版本

完成检查后另存修订版，返回数据中心选择新版本。旧数据和旧账户的依据保持可追溯。

完成后核对：新版本的规则与权益要求通过；存在未解决错误时不能把版本生成当作可回测证明。
