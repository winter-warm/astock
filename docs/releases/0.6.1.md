# AStock 0.6.1

发布目标：[winter-warm/astock](https://github.com/winter-warm/astock)，标签 `v0.6.1`。2026-11-15 用户已确认项目验收。构建前验证以 `docs/tutorial-release-baseline.json` 为准；便携包、单实例、附件摘要与发布结果见 Release 及源码附带的最终报告。

## 本版变化

- 自然波动合成教学 K 线使用固定种子的日内路径，实体和上下影随行情变化；保留旧样本及原运行来源。
- 数据选择、图表、结果、归档和报告统一显示真实历史、真实录制、合成教学或真实性待核对。
- 指数点位支持指标与信号研究；直接指数委托明确拒绝，不构造可交易的指数份额。
- 回放速度只作用于快照等待；K 线回测使用暂停和下一时刻观察。
- 修正策略接口独立窗口、回测设置和取消行为、资金范围、数据选择及视图菜单。
- 将固定应用图标随程序打包，设置 Qt 应用图标与稳定的 Windows 应用标识，统一窗口及任务栏图标。
- 保留六页工作区、当前草稿回测、历史/模拟账户隔离、单实例和 35 步 7 章节教程。公开课程为 12 模块、72 课。
