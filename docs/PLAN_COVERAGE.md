# 原计划覆盖审计

当前整理目标为 **0.6.1**，核对日期 2026-11-15。用户已确认项目验收。619 项回归（失败、错误、跳过均为 0）、Ruff 和四组界面矩阵已通过；每组覆盖 78 个页面状态、259 个控件。当前轮 72 个 Notebook 均已使用独立内核执行通过。构建前验证以 `tutorial-release-baseline.json` 为准，便携包与公开发布结果见 Release 及源码附带的最终报告。本表区分已实现能力与尚未覆盖的测试范围，不复用旧版测试数量证明本版发布通过。

| 计划要求 | 当前实现 | 范围与后续事项 |
|---|---|---|
| 策略编写与清晰入口 | 六页左导航，默认内嵌编辑器；模板、新建、导入、参数、保存与当前草稿回测 | 页面切换不自动运行或下单；历史结果保留独立策略快照 |
| 历史回测与分析 | 区间/基准、净值、回撤、成交归因、分月表现、运行依据 | K 线按下一根开盘撮合，不推断柱内路径 |
| 模拟交易与账户隔离 | 自动策略和手动练习、资金/持仓/委托/成交、暂停与停止撤单 | 本地虚拟资金；未接券商柜台 |
| 归档、对比和导出 | 账户与记录集中只读查看，后台一致快照对比及 HTML/CSV/JSON 导出 | 比较须核对数据、费用、规则、策略和运行状态 |
| 历史数据与来源 | 下载、导入、覆盖/权益/证券规则检查；统一真实、合成和待核对标识 | 数据真实性与权益/规则完整性分别判断，失败不补造价格 |
| 自然教学 K 线 | 固定种子的日内路径生成实体与上下影，旧教学数据保留 | 仅用于流程学习，不是实际市场样本 |
| 指数研究 | 读取指数点位、计算指标与信号；拒绝直接买卖指数 | 本机 24 组指数和 48 组个股资料不随公开包发布 |
| 录制与回放 | 输入分块、异常录制恢复、暂停/单步；速度仅作用于快照等待 | K 线回测禁用回放速度；不重演未记录的人工操作 |
| 量化课程与使用教程 | 12 模块 72 课、代码运行/Notebook、自测与学习状态；35 步 7 章节操作引导 | 旧四课/QMT 八课入口不再公开；各版历史记录保留 |
| 桌面布局与响应 | 原生 Qt、深浅主题、页面布局、后台数据任务与独立策略进程 | 本版分辨率/缩放覆盖以新界面矩阵实测结果为准 |
| 仿真账本与恢复 | 冻结、撤单、部分成交、费用、分红送转、账本重建与损坏隔离 | 支持范围见 RULES；旧记录缺失的历史流水不推算伪造 |
| 日期与证券规则 | 股票/ETF 规则、当前 ETF 属性、按日启用和有来源的区间修订 | 完整 ETF 历史属性、特殊无限制日期和 2023—2026 外日历待扩展 |
| 单实例和初始化 | 重复启动唤起已有窗口；初始化先停止任务并关闭数据库 | 初始化另行确认、不备份且保留学习数据；发布不执行初始化 |
| 可复现交付 | 锁定依赖、源文件摘要、正式门禁、便携包、Notebook、SHA256 | 本版结果由新交付清单与基线绑定，旧报告保留为历史 |
| 实盘时段及环境验收 | 有公开接口探测与离线错误路径记录 | 盘中连续一小时、真实 QMT 迁移和 Windows 10 实装仍无通过结论 |

## 历史与后续

0.1 系列逐步补齐订单回调、权益账本、数据目录、质量检查、证券规则、报告与输入恢复；0.2—0.4 增加 QMT 风格工作流及长期课程；0.5 统一导航；0.6 明确工作区和策略身份。各轮原始验收保存在 [VALIDATION](VALIDATION.md)，其界面入口与测试数量只适用于当时版本。

后续优先补充开市连续行情稳定性、不同机器环境及新手使用反馈，并继续扩展有证据支持的历史规则。公开接口的一次成功不能代表持续服务或完整历史覆盖。
