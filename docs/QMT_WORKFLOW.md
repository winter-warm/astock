# QMT 迁移参考

本页按 **0.6.1** 的实际入口说明研究流程与平台差异。公开界面只有六页左导航，旧八课 QMT 自测和早期截图布局不再作为用户入口。AStock 没有连接 QMT 柜台，也不提供 QMT API 兼容层。

| 任务 | AStock 当前入口 | 迁移时需要核对 |
|---|---|---|
| 编写策略 | 写策略；中央源码、右侧参数；模板与已存策略 | Python 类和回调接口 |
| 准备数据 | 数据中心；历史数据、实时行情两个标签 | 数据来源、周期、时间标记、复权和权益资料 |
| 历史实验 | 写策略 → 去回测；历史回测中确认并开始运行 | 当前草稿、资金、费用、区间、基准及撮合规则 |
| 分析当前运行 | 历史回测的净值、回撤、成交和诊断 | 实际处理范围与信号/成交时点 |
| 实时仿真 | 模拟交易；策略账户、行情快照及手动练习 | 本地虚拟账户与柜台账户不是同一种执行环境 |
| 查询与留存 | 账户与记录；运行依据、对比、报告 | 结果所用的代码、参数、数据及规则版本 |
| 学习 | 量化课程 72 课；帮助 → 使用教程重放 | 35 步操作引导与量化知识课程各自的用途 |

## 接口与执行差异

AStock 使用 `UserStrategy(Strategy)` 及 `initialize/on_bar/on_quote/on_order`，与 QMT 的 `init/handlebar`、`ContextInfo` 不同。迁移时须逐项改写数据、订单和回调接口，不能直接替换名称后认定结果一致。

本地 K 线在下一根开盘撮合；快照按实际接收顺序推进，回放速度只改变快照间隔。指数点位可以研究但不能直接下单。当前草稿与历史结果分开保存，分月基准为价格基准，不含分红再投资；收益差以百分点计，不直接称为 Alpha。

前后区间选择是独立探索/检验的便捷入口，不等于自动参数搜索或滚动样本外验证。完整 ETF 历史属性、特殊交易日和平台实际成交机制仍须另外核对。

## 历史依据与验证边界

0.3—0.4 的模型列表、独立编辑窗口和回测布局曾参考迅投公开截图；旧参考不表示 0.6.1 继续保留相同入口，也不证明所有券商版本一致。历史截图保存在本机旧验收材料中。

本版构建前验证中，619 项回归（失败、错误、跳过均为 0）、Ruff 和四组界面矩阵已通过；每组覆盖 78 个页面状态、259 个控件。当前轮 72 个 Notebook 均已使用独立内核执行通过。当前证据由 `tutorial-release-baseline.json` 绑定，便携包及公开发布结果见 Release 与源码附带最终报告。真实 QMT 客户端迁移及盘中连续一小时验证仍未取得通过结论。旧四课/QMT 学习记录仅用于兼容。
