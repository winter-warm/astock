# 项目当前状态

2026-11-15，用户已确认项目验收，本轮将最新本地改动整理为 **AStock 0.6.1** 公开发布版。发布目标为 [winter-warm/astock](https://github.com/winter-warm/astock)，标签 `v0.6.1`。构建前验证以当前发布基线为准，便携包、单实例、附件摘要和公开发布结果见 Release 及源码附带的最终报告。

## 当前功能

唯一左侧导航，默认直接打开“写策略”。

| 页面 | 职责 |
|---|---|
| 写策略 | 编辑 Python，在右侧检查和修改参数，保存或携带当前草稿去回测 |
| 历史回测 | 核对待运行策略、数据、区间及资金，运行并分析净值、回撤和成交；调试控制默认折叠 |
| 模拟交易 | 管理运行中的虚拟账户、行情、委托、成交及手动练习 |
| 数据中心 | 下载、导入、检查和选择历史数据；第二标签查看实时行情 |
| 账户与记录 | 只读归档、运行依据、报告导出及跨运行对比；按账户模式打开详情 |
| 量化课程 | 12 模块、72 课，阅读、自测、代码练习和 Notebook 导出 |

“去回测”携带当前草稿及参数；历史结果保留自己的策略快照。历史回测和模拟交易分别记住当前账户，后台更新不能覆盖另一个工作区。使用教程为 35 步、7 章节，首次启动自动显示，帮助菜单可重放；旧互动/QMT 课程入口仅兼容历史记录，不再公开。

本版纳入自然波动合成教学 K 线、统一的真实/合成/待核对来源标识、指数点位研究及指数委托拒绝，以及只用于快照的回放速度。策略接口窗口、回测设置、资金范围、数据选择和视图菜单的本地修复也纳入本版。固定应用图标随程序发布，并设置 Qt 应用图标和稳定 Windows 应用标识，修复窗口与任务栏图标。

## 发布与数据范围

- 正式交付目录：`dist/release-0.6.1/`。公开附件为 Windows x64 程序、源码、课程 Notebook 和 `SHA256SUMS`；说明见 [0.6.1 发布记录](releases/0.6.1.md)。
- 公开下载用户完整解压程序包，运行 `AStock/AStock.exe`；便携数据保存在该程序旁的 `data`。
- 项目本机仍通过 `AStock.lnk` 或 `启动AStock.ps1` 读取 `dist/交付记录.json`。当前程序路径以索引 `current_app` 为准，账户、策略、行情和学习状态继续使用根 `data`。
- 本轮清理旧程序与重复产物，保留旧源码和验收证据。根 `data` 不初始化、不迁移、不备份；此前已有备份不属于本轮新建结果。
- 16 只股票、8 类指数的 72 组真实数据是本机验收资料，保留在现有数据目录，**不随公开程序、源码或 Notebook 包发布**。下载用户通过数据中心获取或导入自己的数据。详见 [本机数据清单](DATA_LIBRARY_2026-11-15.md)。
- 公开包不包含本机账户数据库、用户策略记录、私人笔记、备份及开发环境。

重复启动会唤起已运行窗口。升级前退出旧版，避免单实例机制把新启动请求交给旧进程。GUI 正常显示，外层启动控制台可以隐藏。

## 验收与边界

0.6.1 最终源码的构建前检查：619 项回归（失败、错误、跳过均为 0）、Ruff 和四组界面矩阵已通过；每组覆盖 78 个页面状态、259 个控件。当前轮 72 个 Notebook 均已使用独立内核执行通过。记录位于 `output/tutorial-release-20261115-222453`，以 `docs/tutorial-release-baseline.json` 绑定的报告为准。576 项正式 0.6.0 回归、619 项后续本地回归及专项记录均是历史证据，不能替代本版完整发布检查。

用户确认验收不扩大以下技术测试范围：本轮公开发布不包含券商实盘、付费模型调用、盘中连续一小时稳定性、真实 QMT 客户端迁移或 Windows 10 实装结论。历史证券属性和特殊交易日期仍有既有覆盖边界；教学样本收益不作为市场盈利证据。

“帮助 → 初始化应用”是另行确认的删除操作，会清空业务数据且不备份，保留学习状态和 `learning` 内 Notebook。发布和旧程序清理不需要执行它。
